# Git Commit & Push Rule

Always commit and push changes to the remote repository after completing tasks or making updates.

- Remote Repository: `https://github.com/sarwesv/Prodigymind.git`
- Main Branch: `main`
- Workflow:
  1. Verify code syntax / functionality before committing.
  2. Stage changes: `git add .` (or specific modified files).
  3. Commit with a clear, descriptive message: `git commit -m "..."`.
  4. Push to remote: `git push origin main`.
